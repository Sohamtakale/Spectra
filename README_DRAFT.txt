# SPECTRA - Smart Media Gazette

## 📌 Purpose of the Website
SPECTRA is an AI-powered media aggregating and analysis platform designed to combat misinformation and provide clarity in the digital age. It serves as a "retro-modern lens," offering users a curated, nutritionally-labeled news feed while empowering them to analyze specific headlines for bias and factual accuracy.

### How It Works?
- **Automated Curation**: Aggregates top headlines across Geopolitics, Silicon Valley (Technology), and the Biosphere (Science).
- **AI Analysis**: Users can "Investigate Headlines" to receive detailed dossiers on bias, owner financing, and factual verification.
- **Trust Rank**: A gamified system where users earn "Investigator Rank" (e.g., Novice, Truth Seeker) by engaging with verified content.

### How It Helps the User?
- ** Combats Fake News**: Provides instant analysis of credibility and bias.
- ** Promotes Media Literacy**: Offers educational resources to help users identify misinformation.
- ** Saves Time**: delivering a centralized, clean, and distraction-free news reading experience.

---

## 🌟 Features

✔ **Smart News Feed** - Curated headlines from top global sources, categorized for easy reading.
✔ **AI Dossier Analysis** - "Investigate" any article url to get a breakdown of bias, funding, and accuracy.
✔ **Nutrition Labels for News** - Visual indicators of source credibility and ownership on every article card.
✔ **Gamified Trust System** - Users level up their "Investigator Rank" by analyzing and verifying news.
✔ **Admin Console** - Specialized dashboard for managing source metadata and moderation flags.
✔ **Media Literacy Hub** - curated educational resources to improve digital information consumption.
✔ **Secure Authentication** - Seamless sign-in via Google (powered by Supabase).

## 🛠️ Tech Stack & APIs Used

- **Frontend:** Next.js 16 (React, Turbopack)
- **Styling:** Tailwind CSS v4, Framer Motion
- **Backend:** Supabase (Auth & Database)
- **AI/Intelligence:** Groq SDK (LLM Analysis), Serper API (Search)
- **News Data:** NewsAPI
- **Icons:** Lucide React
